This demo shows how a college portal can bring common administrative tasks into one simple interface. It includes a responsive frontend, a Python Flask backend, and a SQLite database.

HTML, CSS and JavaScript create the responsive user interface.

02

Backend

03

Database

SQLite stores student records and notices between restarts.

Project note: This is a learning demo. Authentication and production security controls are not included.
