COLLEGE MANAGEMENT SYSTEM — FULL-STACK DEMO

Included:
- Frontend: HTML, CSS, JavaScript
- Backend: Python + Flask
- Database: SQLite (college.db is created automatically)
- Dashboard, student records (add/search/delete), notices (add/delete), About page

RUN ON WINDOWS:
1. Install Python 3 from https://www.python.org/downloads/ if needed.
2. Extract this ZIP into a folder.
3. Open Command Prompt in that folder.
4. Run: py -m pip install -r requirements.txt
5. Run: py app.py
6. Open the local address printed in the terminal (usually http://127.0.0.1:5000).

RUN IN VS CODE:
1. Open the extracted folder.
2. Open Terminal > New Terminal.
3. Run: py -m pip install -r requirements.txt
4. Run: py app.py
5. Open http://127.0.0.1:5000 in your browser.

IMPORTANT:
- This is a college project/demo, not a production-ready system.
- No login/authentication is included. Do not enter real/private student information.
- Before real deployment, add authentication, role permissions, CSRF protection, secure configuration, backups, and validation.
